# Mesh Avatar Studio

[English](README.md)

1枚のイラストから、まばたき・口パク・首振り・呼吸・髪の揺れをする 2D メッシュアバターを作るツールです。アバターの作成はコーディングエージェントが行い、細かい調整はプレビューを見ながらローカルのエディタで行います。

![ミコのサンプルを開いたエディタ](docs/images/ja/01-overview.png)

## サンプルで試す

Node.js 22.17 以上が必要です。

```sh
npm install
npm run dev
```

ターミナルに表示された URL(例: `http://127.0.0.1:5173/`)をブラウザで開くと、同梱のサンプル(チャイナドレスのミコ)が表示されます。左の一覧からパーツを選び、画像の上の点をドラッグすると、右のプレビューに結果が反映されます。サンプルは読み取り専用なので、編集すると「コピーして編集を続ける」ボタンが出ます。押すと自分用のコピーで作業を続けられます。

### Windows で使うとき

リポジトリの取得には、できれば `git clone` を使ってください。ZIP を使う場合は、展開する前にエクスプローラーで ZIP のプロパティを開き、ブロック解除の項目があれば解除してください。

エージェントに作業を頼む前に、自分の Windows アカウントで `projects/` フォルダを作っておいてください。別のアカウントやサンドボックス内で動くエージェントが作ったフォルダは、アクセス権限の違いでエディタから読めないことがあります。読めない場合は、フォルダの「プロパティ → セキュリティ」で、自分のアカウントにプロジェクト全体へのアクセス権限を付け直してください。中のファイルやサブフォルダにも権限が引き継がれるように設定します。

## 使い方の流れ

自分のイラストからアバターを作る手順は4つです。1と4はこのリポジトリで動かすコーディングエージェント(Claude Code または Codex)が行い、2と3はエディタで行います。

### 1. エージェントにアバターを作ってもらう

このリポジトリのフォルダで Claude Code か Codex を開き、イラストを渡して次のように頼みます。

> docs/agent-guide.md に沿って、この画像からアバターを作って: `/path/to/your-image.png`

エージェントは[エージェント向けの手順書](docs/agent-guide.md)に従って作業します。座標を正確に読めるかを確認したうえで、目盛り付きの拡大図を見ながらリグを配置し、画像をレイヤーに切り出して、決まったポーズの画像で仕上がりを確認します。作ったプロジェクトは `projects/<名前>/` に保存され、git にはコミットされません。正面向きのバストアップで、背景が透明な PNG がいちばんきれいに仕上がります。

エディタで何もプロジェクトを開いていないときは、この依頼文をコピーできる形で表示します。

![新しいアバターの依頼文](docs/images/ja/06-new-project.png)

推奨する組み合わせは次のとおりです。

| エージェント | モデル |
|---|---|
| Claude Code | Claude Opus 5.5 |
| Codex | GPT-6.1 Sol |

### 2. プロジェクトを開いて確認する

エディタを起動し(`npm run dev`)、「プロジェクトを開く」の一覧から作ったプロジェクトを選びます。プレビューの「ポーズ確認」で顔の向きや傾き、目の開閉を、「口の動き」で母音ごとの口の形を確かめます。

![口の動きの確認](docs/images/ja/03-lip-sync.png)

### 3. おかしいところをドラッグで直す

左の一覧でパーツを選ぶと、画像の上にそのパーツの点が強調して表示されます。点をドラッグして位置を直してください。変更はプレビューにすぐ反映されます。ただし、目や手の輪郭と、髪のマスクに使う頭・髪・お団子の範囲は、画像をレイヤーに切り出すときにも使います。これらを変えると画面の上に帯が出るので、「保存してレイヤーを作り直す」を押してください。数秒で終わります。

![目の輪郭の編集](docs/images/ja/02-edit-handles.png)

![輪郭を変えたあとのレイヤーの作り直し](docs/images/ja/04-rebuild.png)

拡大・縮小はピンチか Ctrl/Cmd+スクロール、移動は2本指のスクロールか、点のない場所のドラッグで行います。「選択中のパーツに合わせる」を押すと、選んでいるパーツまで拡大します。

### 4. 目と口の描き分け画像を作る

描き分け画像がない間は、目と口をメッシュの変形だけで動かしています。閉じた目や母音ごとの口の絵を用意すると、まばたきと口の動きがかなり自然になります。「描き分け画像」の欄で「目」「口」の片方または両方にチェックを入れ、表示された文章をコピーして、このリポジトリのフォルダで開いた Codex に貼り付けてください。Codex が組み込みの画像生成で絵を作って取り込み、エディタが自動で読み込み直します。Claude Code は画像を生成できないため、Claude Code 向けの文章では、マスクと依頼文を用意して画像生成に渡すファイルを案内するところまでを頼みます。

![口の描き分けの依頼](docs/images/ja/05-variants.png)

## カメラで動かして配信する

![配信の操作画面](docs/images/ja/07-live.png)

エディタでプロジェクトを開き、「配信」を選びます。カメラを開始し、目と口の力を抜いて口を閉じ、正面を向いた状態で「正面の姿勢を登録」を押してください。左右反転、感度、動きのなめらかさを調整できます。マイクで口を動かすこともできます。映像と音声は端末内で処理し、配信用画面に渡すのはアバターの動きの数値だけです。

背景を選んで「OBS用URLをコピー」を押し(先に見た目を確かめたいときは「OBS用の画面を別タブで開く」)、操作画面を開いたまま、OBSの「ブラウザ」ソースにURLを貼り付けます。サイズは **1080 × 1080** などに設定してください。背景が透明なら、そのままOBSで重ねて表示できます。ほかのソフトで取り込む場合は、緑の背景にしてクロマキーで抜く方法も使えます。

どちらの画面もローカルの開発サーバー(`npm run dev`)で使います。操作画面からの更新が止まると、配信用画面は待機動作に戻ります。

「ライティング」を有効にすると、ドラッグで動かせる光源に合わせてアバターに陰影が付きます。初期状態はオフです。配信の操作画面の下のほう、またはエディタのプレビューの下にある欄で設定でき、設定はOBS用URLにも含まれます。詳しくは[リファレンス](docs/reference.md#lighting)(英語)を参照してください。

操作画面は専用のウィンドウで開いたままにしてください。OBS用URLはOBSの中か別のタブで開き、操作画面のタブには貼り付けないでください。画面が隠れて追跡が停止・低速になったという表示が出た場合は、操作画面のウィンドウを前面に戻してください。

![緑の背景にした配信用の画面](docs/images/ja/08-stream.png)

「表情」のボタンか、キー1〜8で、笑顔、驚き、ウインクなどに切り替えられます。切り替えている間も、まばたきや口の動きはカメラとマイクに合わせて動きます。macOS の「ショートカット」アプリや Stream Deck のボタンを使えば、他のアプリを操作中でも切り替えられます([設定方法](docs/reference.md#switching-expressions-from-other-apps)、英語)。

カメラは使わなくてもかまいません。マイクだけをオンにすると、アバターは待機動作を続けながら、声に合わせて口を動かします。Zoom や Google Meet などの Web 会議にアバターで参加するときは、OBS の仮想カメラを使います([手順](docs/reference.md#video-calls)、英語)。

配信用画面の URL で指定できる項目、うまく動かないときの確認点、プライバシーについては[リファレンス](docs/reference.md#live-and-streaming)(英語)にまとめています。
