# クラウドのエージェントにアバターを作ってもらう

[English](cloud-agents.md) · [简体中文](cloud-agents.zh.md)

> この翻訳と英語版([cloud-agents.md](cloud-agents.md))の内容が食い違う場合は、英語版に従ってください。

専用のクラウドのコンピュータを持つエージェント(Dot、Muse、Grok Bot など)に、スマホから絵を1枚渡して
アバターを作ってもらう手順です。サービスが対応していれば、自分で開いて動かせるページにも載せてもらえます。
所要時間は30分前後です。Dot で試したときは28分でした。
エディタでの手直しは、この手順には含みません。あとから手直しするには、元画像を含む完成したファイルを
Studio の「.mavatar を取り込む」(Import .mavatar)で開いてください。

## 確認状況

2026年11月時点の結果です。

| エージェント | 作る | 見せる |
|---|---|---|
| Dot (OpenAI) | 確認済みです。 | 確認済みです。Sites に載せ、本人だけが見られる状態でスマホから開けました。マイクでの口パクも動きました。 |
| Muse (Meta) | 利用者から成功の報告があります。メンテナーは未確認です。 | 利用者から、Space の中で動かせたとの報告があります。メンテナーは未確認です。 |
| Grok Bot (xAI) | 確認済みです。エージェントのコンピュータ内で、表情の切り替えまで動きました。 | 方法が見つかっていません。Pages はスクリプトを実行できず、コンピュータ上のサーバーを外に通す方法(トンネル)も失敗しました。`.mavatar` ファイルを受け取り、Player で開いてください。 |

「確認済み」は、メンテナーが実際に試した結果を指します。サービス側の機能は変わるため、
ここに載せているのは確認した時点の結果です。

## 送る文面

画像を1枚添付し、次の文面をコピーして送ってください。正面向きで顔と肩が写っている、
背景が透明の PNG が向いています。

```text
添付した画像1枚から、Mesh Avatar Studio で動く2Dアバターを作ってください。

リポジトリ: https://github.com/shinshin86/mesh-avatar-studio

手順
1. 環境の確認: Node.js(22.17以上)、Git、Python(3.10以上)、uv があるか調べ、
   足りないものを入れる。
2. 導入: `npx create-mesh-avatar-studio` を実行する。できたフォルダで
   `npx playwright install chromium` と `npm run doctor` を実行し、警告が残ったら直す。
3. 作成: フォルダ内の `docs/agent-guide.ja.md` を最初から順に進める。
   各ステップの確認は飛ばさない。
4. 描き分け(手順書のステップ6): 画像生成が使えるなら、閉じ目と口の形を作る。
   この画像を画像生成に渡すことに同意します。
5. 書き出し: `npm run pack-avatar -- projects/<名前>` で .mavatar ファイルを作る。
6. 見せる: あなたの環境に、作った Web ページを私が開ける機能(サイトやスペースなど)が
   あれば、アバターを表示するページを作り、私だけが見られる状態で載せる。
   なければ .mavatar ファイルを私に渡す。

ページの中身
<script type="module" src="https://cdn.jsdelivr.net/npm/mesh-avatar-element@0/dist/standalone.js"></script>
<mesh-avatar src="./character.mavatar"></mesh-avatar>
表情を切り替えるボタンと、マイクで口を動かすボタンも付ける
(リポジトリの packages/element/README.md に例がある)。

守ること
- Mesh Avatar Studio のリポジトリには、画像も作ったファイルもコミットしない。
  このリポジトリに push しない。
- 手順6で、私だけが見られるページを載せるために必要な保存は行ってよい。
- 誰でも見られる状態にする前に、必ず私に確認する。
- 中断しても再開できるように、各ステップの終わりに projects/<名前>/HANDOVER.md へ
  進み具合を書く。再開するときは最初にこれを読む。
```

画像生成に絵を渡したくない場合は、手順4を「描き分けを飛ばす」に書き換えてください。
飛ばすと、まばたきと口の動きはメッシュの変形だけになります。

コミットの禁止は、Mesh Avatar Studio のリポジトリに限っています。エージェントがページを載せるとき、
サービス専用の保存先へのコミットが必要な場合があるためです。「一切コミットしない」と広く禁止すると、
手順6が止まることがあります。

## 絵の扱いとプライバシー

絵はエージェントの提供元に送られます。描き分けを頼む場合は、画像生成にも送られます。
`.mavatar` には、元画像を含めない場合でも絵のほぼ全体が入っています([アバターの形式](format.md)、英語)。
ページを誰でも見られる状態にすると、絵もダウンロードできる状態になります。
まずは本人だけが見られる状態で載せ、公開するかどうかは自分で決めてください。

## うまくいかないとき

- **Chromium のダウンロードが失敗する:** 同じ版を、公式の別の配布元から取得するよう頼んでください。
- **エージェントのコンピュータから CDN に接続できない:** リポジトリで `npm run build:element` を実行し、
  `packages/element/dist/standalone.js` をページと一緒に置いて、CDN の URL の代わりに読み込ませてください。
- **エージェントが操作するブラウザで WebGL2 が使えず、載せたページの表示を確かめられない:**
  載せる前に、Playwright の Chromium で同じページが動くことを確かめるよう頼んでください。
- **ページの機能がスクリプトを実行できない(Grok Bot の Pages など):** そのページでは動かせません。
  `.mavatar` ファイルを受け取り、[Player](https://shinshin86.github.io/mesh-avatar-studio/ja/play/) で開いてください。
